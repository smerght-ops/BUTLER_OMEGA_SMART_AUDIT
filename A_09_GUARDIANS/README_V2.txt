======================================================================
GENIE V2 : ARCHITECTURE MANIFESTO & PASSPORT
======================================================================

1. НАЗНАЧЕНИЕ ПЛАТФОРМЫ
GENIE V2 — это модульная система инженерного контроля (CI/CD) для ИИ.
Её задача: валидация, верификация и блокировка опасных изменений ДО их физической записи на диск.

2. СТРУКТУРА СЛОЁВ (V2 LAYER)
Новая архитектура жестко разделена на 4 зоны ответственности:
- /Config    : Декларативные схемы (guardians.json, pipeline.json), управляющие логикой.
- /Engine    : Оркестратор (genie_engine.ps1), который ничего не знает о коде, а только читает Config и запускает Guardians.
- /Guardians : Изолированные скрипты проверок (gate.ps1, candidate.ps1 и др.).
- /Observer  : Слой аналитики, сбора метрик и карантина отклонённых патчей.

3. STATUS: LEGACY LAYER
Все скрипты genie_*.ps1, находящиеся в корне A_09_GUARDIANS, считаются LEGACY.

Разрешается:
• исправление ошибок;
• критические исправления безопасности;
• документирование.

Запрещается:
• разработка нового функционала;
• создание новых genie_*.ps1 в корне A_09_GUARDIANS.

Новый функционал разрабатывается только в архитектуре GENIE V2.

4. ПРАВИЛО МИГРАЦИИ
Перенос функционала из Legacy в V2 осуществляется путем создания чистого скрипта в папке /Guardians и его регистрации в /Config/guardians.json.
