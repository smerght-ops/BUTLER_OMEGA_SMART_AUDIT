# DAILY START CHECKLIST

## Ежедневный порядок работы

[ ] 1. Открыть и при необходимости перечитать A_00_ARCHITECTURE\CONSTITUTION.md.

[ ] 2. Убедиться, что все текстовые файлы сохраняются в UTF-8 БЕЗ BOM.

[ ] 3. Проверить, что:
    - user_profile.json — единственный источник пользовательских фактов;
    - USER_MEMORY.md генерируется автоматически;
    - MEMORY.md содержит только конституцию и архитектурные правила.

[ ] 4. Перед массовыми изменениями создать резервную копию изменяемых файлов.

[ ] 5. После изменения Python-кода выполнить:
    python -m py_compile <имя_файла>

[ ] 6. После крупных изменений выполнить лабораторный тест памяти и чата.

[ ] 7. Не публиковать незавершённые PowerShell-команды и не оставлять незакрытые конструкции.

[ ] 8. При обнаружении ошибки сначала выполнить проверку, затем исправление.
