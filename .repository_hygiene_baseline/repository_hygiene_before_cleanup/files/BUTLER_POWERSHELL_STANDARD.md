# BUTLER POWERSHELL STANDARD

## Запрещено

- else
- elseif

## Предпочтительно

- if
- return
- continue
- break
- foreach
- try/catch
- Copy -> Move
- Backup перед изменением
- MANUAL ROLLBACK

## Не рекомендуется

- сложные Where-Object
- длинные конвейеры
- вложенные вычисления
- неявные конструкции

## Правило

Команды должны быть:
- короткими;
- читаемыми;
- последовательными;
- безопасными;
- без else.
