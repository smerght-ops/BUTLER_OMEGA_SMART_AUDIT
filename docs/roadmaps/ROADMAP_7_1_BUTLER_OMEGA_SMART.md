============================================================
ГЛАВНЫЙ ПРИНЦИП ПРОЕКТА
============================================================

Каждый новый этап должен отвечать
на простой вопрос пользователя:

"Что нового Butler сможет сделать для меня?"

Если после завершения этапа пользователь
не получил новую полезную возможность,

значит этап считается незавершённым.

============================================================
ПРОФЕССИОНАЛЬНЫЕ ВЕРТИКАЛИ BUTLER — БУДУЩИЙ РЕЗЕРВ
============================================================

После формирования базовой Desktop Automation допускается
развитие профессиональных пользовательских возможностей
поверх существующей архитектуры Butler.

Приоритетные направления:

1. ENGINEERING COMPLIANCE
Проверка проектов, документов и решений по ГОСТ / СП /
техническим регламентам с обязательной трассировкой:
требование → источник → объект → результат проверки.

2. COSTING / ВОР / СМЕТЫ
Извлечение объёмов и позиций, связь с проверяемыми базами
расценок, расчёт стоимости и формирование Excel / отчётов.

3. BIM / CAD ORCHESTRATION
Преобразование человеческого задания в параметры и команды
для существующих BIM/CAD-инструментов и их API.
LLM управляет процессом, но не заменяет геометрический движок.

4. CONSTRUCTION CV
Анализ фото, видео, point cloud и данных стройплощадки,
сопоставление факта с BIM / проектом и выявление отклонений.

5. ANALYTICS
Excel / BI / отчёты / графики как общий слой представления
результатов профессиональных вертикалей.

КРИТИЧЕСКИЙ ПРИНЦИП:

LLM НЕ является источником инженерной истины.
LLM понимает намерение, извлекает структуру и управляет tools.

Норматив, стоимость, геометрия, измерение и математический
результат должны происходить из проверяемого источника
или детерминированного специализированного инструмента.
