## Что внедряем сейчас

### 1. BUTLER_OS.py

Главный чистый терминал проекта.

Задача:
- принимать текст;
- передавать в dispatcher_bridge_v2;
- красиво выводить ответ отдела.

Без сложной логики.

---

### 2. Project Context Reader

Обязательный модуль перед сложным кодингом.

Задача:
- читать структуру проекта;
- видеть ключевые файлы;
- понимать зависимости;
- передавать CodingDepartment не кусок кода, а архитектурный контекст.

Это Senior Coding Pattern.

---

### 3. Self-Healing Loop

Только в песочнице:

A_00_AVARIYKA

Задача:
- запускать код;
- читать stderr;
- передавать ошибку суб-агенту;
- повторять исправление до exit code 0;
- не трогать боевое ядро без подтверждения.

---

## Что внедряем позже

### 4. Infilling Tool

Инструмент точечной вставки кода в середину файла.

Задача:
- брать файл;
- находить безопасную точку вставки;
- делать backup;
- вставлять блок;
- компилировать;
- откатывать при ошибке.

---

### 5. Voice Input

Локальный Faster-Whisper.

Задача:
- голос -> текст;
- текст -> dispatcher;
- результат -> отдел.

---

## Что пока НЕ внедряем

### DiffusionGemma / diffusion coding

Статус: PARKED.

- нельзя ломать рабочий Butler Omega ради экспериментального backend.
