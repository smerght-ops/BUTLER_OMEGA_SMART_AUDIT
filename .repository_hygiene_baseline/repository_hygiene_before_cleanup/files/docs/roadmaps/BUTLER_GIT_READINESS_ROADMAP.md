# BUTLER GIT READINESS ROADMAP
Version: 1.0
Status: APPROVED
Date: 2026-08-01

---

# Цель

Подготовить проект BUTLER_OMEGA_SMART к безопасному хранению
в приватном GitHub-репозитории без утечки пользовательских данных,
секретов и служебной информации.

Работа выполняется строго по этапам.

Переход к следующему этапу допускается
только после подтверждения предыдущего.

---

## ЭТАП 0
READ ONLY — Инвентаризация

Исполнитель:
PowerShell + пользователь

Результат:

- карта проекта;
- классификация KEEP / ARCHIVE / IGNORE / DELETE;
- без изменений файлов.

Статус:
[ ]

---

## ЭТАП 1
Git Certification v1

Исполнитель:
Codex

Цель:

Подготовить текущий проект к GitHub.

Задачи:

- создать .gitignore;
- исключить backup;
- исключить cache;
- исключить __pycache__;
- исключить модели;
- исключить базы данных;
- исключить временные результаты;
- исключить секреты;
- сформировать отчёт PASS / FAIL.

Результат:

GitHub Ready v1

Статус:
[ ]

---

## ЭТАП 2
PowerShell Validation

Исполнитель:
PowerShell

Цель:

Проверить фактический состав файлов,
которые попадут в Git.

Подтвердить:

PASS / FAIL.

Статус:
[ ]

## ЭТАП 3
Git Certification v2

Исполнитель:
Codex

Создать встроенный компонент Butler:

GitCertificationInspector

Функции:

- анализ проекта перед commit;
- поиск секретов;
- поиск backup;
- поиск log;
- поиск временных файлов;
- поиск моделей;
- поиск баз данных;
- поиск запрещённых файлов.

Результат:

Автоматическая сертификация Git.

Статус:
[ ]

Acceptance

Исполнитель:
PowerShell

- .env

- TOKEN
- PASSWORD
- backup
- *.bak
- __pycache__
- *.db
- *.gguf
- *.log

Результат:

PASS / FAIL

Статус:
[ ]

---

# Главные принципы

- никаких пользовательских данных в GitHub;
- никаких паспортов, документов и памяти пользователя;
- никаких API-ключей;
- никаких секретов;
- сначала проверка — потом публикация;
- все изменения подтверждаются проверками.

Получить проект:

BUTLER_OMEGA_SMART

со статусом:

GitHub Ready

без снижения безопасности
и с возможностью дальнейшего архитектурного аудита.
